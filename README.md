## Projects Planned for 2026-2027
- [ ] Audio/Video Summarization and Learning tool
    It will use Whisper and an LLM of your choice.
    You bring your own key and provider.
    Designed to be (more or less) self hostable.
    You upload a file or add a youtube link, then the transcript (and possibly other relevant information? Metadata?) get pulled, fed into an LLM, and then you can ask questions, create flashcards or export transcript or your conversation with the LLM.
    
- [ ] CrintyOS
    Operating System i plan on making from scratch.
    This year, i am only starting the project — i hope to get done with basics like bootloader.
    It will be written in Assembly, C and Rust. It is a learning project, to learn low level architecture of computers as well as these programming languages for my future projects.
    The OS will be POSIX/UNIX/Linux compatible.
    I also plan on porting xorg (or any other display server/protocol) for GUI interfaces.
    
- [ ] Nanoxide Suite
    Suite of very tiny apps, written in Rust+Tauri, serving a single specific purpose. Since Tauri uses web technologies, you would be able to style it with just a css file. The ideas for the apps in the suite include:
    - `nanoxide-symbols`: Lets you quickly look up certain symbols, like em dash, greek letters, et cetera, and copy. You would be able to extend it, sicne i plan on keeping all of the symbols and their synonyms in a csv file or a similar, easily parseable format.
    - `nanoxide-colors`: A color pallete creator and visualizer
    - `nanoxide-chat`: Another bring-your-own-key LLM app with ephemeral history. It is designed for answering very simple questions or for short conversations. You would define base url, your API key, prompt and other parameters in a json file.
    
  The idea is to use the apps of the suite with keybinds, for maximum speed, minimal overhead and quick access to boost your productivity.
